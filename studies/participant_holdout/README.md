# T38 · 留出参与者验证（Leave-participants-out）

T35–T37 的测试日此前都被评估过。时间这个维度已经无法再提供干净的留出集，但"人"这个维度还没用过。T38 想回答的问题是：**模型从来没在训练标签里见过的人，它还能预测得一样好吗？**

数据来源：[T38_RESULTS.json](T38_RESULTS.json)。可用 `python -m src.participant_holdout --verify-only` 从本地逐样本结果重算并核对。

## 方法（拟合前冻结）

- **划分**：每个参与者按 `sha256('T38|salt|dataset|id') mod 2` 分到 A 组或 B 组。预先固定 5 种划分（salt 0–4），报告这 5 次结果的均值和范围。
- **训练**：沿用 T35 冻结的 11 个折。每折只用 **A–A 配对**训练模型和确定阈值；模型、参数、seed 和阈值规则与 T21/T22 相同，不调参。
- **测试**：在每折的测试时刻评估两类配对：**B–B**（两个人都没见过）和 **A–B**（一个人没见过）。
- **参照**：同一批测试样本上，再评估 T35 的全员 XGBoost（训练时见过所有人，但不同时间）和不用标签的 T36 Hawkes。
- **门槛**：训练集、验证集或任一测试总体中，某一类不足 20 行的折会被剔除。实际 5 种划分 × 11 折全部满足条件。

## 结果（7 天窗口，5 种划分的均值；方括号内为最小–最大）

| 测试总体 | 模型 | 合并 AP | ROC-AUC | Brier | NDCG@5 |
| --- | --- | --- | --- | --- | --- |
| B–B（两人都没见过） | **XGBoost（只用 A–A 训练）** | **0.651** [0.631, 0.666] | 0.829 | 0.106 | 0.797 |
| | XGBoost（T35，见过所有人） | 0.668 [0.650, 0.682] | 0.837 | 0.103 | 0.801 |
| | Hawkes（无标签） | 0.634 [0.609, 0.655] | 0.824 | 0.114 | 0.798 |
| | Logistic（只用 A–A 训练） | 0.591 [0.559, 0.618] | 0.819 | 0.114 | 0.793 |
| | 历史频率（只用 A–A） | 0.478 [0.459, 0.497] | 0.779 | 0.139 | 0.748 |
| A–B（一人没见过） | **XGBoost（只用 A–A 训练）** | **0.650** [0.638, 0.661] | 0.825 | 0.109 | 0.796 |
| | XGBoost（T35，见过所有人） | 0.665 [0.660, 0.673] | 0.832 | 0.106 | 0.803 |
| | Hawkes（无标签） | 0.633 [0.628, 0.639] | 0.823 | 0.116 | 0.800 |

| 预设比较（合并 AP 差，B–B） | 5 种划分的差值 | 日块区间不含 0 的划分数 |
| --- | --- | --- |
| 留出 XGBoost − 全员 XGBoost | −0.020、−0.023、−0.015、−0.009、−0.019 | 5/5 |
| 留出 XGBoost − Hawkes | +0.010、+0.019、+0.011、+0.025、+0.022 | 0/5 |

每种划分下的 B–B 测试约有 1.4 万至 1.8 万个样本，正例率约 19.7%，覆盖 11 个测试日。

## 解读与限制

- **对没见过的人，模型依然有效。** 只用 A–A 训练的 XGBoost 在 B–B 上的 AP 为 0.651，只比见过所有人的模型低约 0.017；5 种划分都在同一方向。按人排序的 NDCG@5 几乎相同（0.797 对 0.801）。
- **这个下降是"没见过这些人"和"训练数据更少"两者混在一起的结果。** A–A 配对只占全部训练行的 23%–29%，T38 没有设计"同样数据量、但见过这些人"的对照组，所以无法把两者分开。如果假设训练数据变少不会让模型变好，那么真正的"陌生人代价"最多约 0.02 AP。
- **与 Hawkes 的差距变小了。** 留出 XGBoost 比 Hawkes 高 0.010–0.025，但没有一种划分的日块区间排除 0。也就是说，对陌生人群，监督模型相对于不用标签的点过程的优势并不稳定。
- **其他限制。** 测试日以前都被评估过。网络特征（共同邻居、度数）用的是所有参与者过去的接触，不含任何标签。5 种划分共用同一批人，不是彼此独立的重复实验。区间只描述日间波动。
