# T35 · 滚动起点重评估（Rolling-origin re-evaluation）

T21/T22 主实验只有 4 个测试日，达不到预设的 8 天 bootstrap 门槛。T35 不改动任何模型设置，用滚动起点的方式重新划分同一 Copenhagen 冻结队列，使每个可用的预测日各自成为一个测试折，从而得到 11 个测试日。

数据来源：[T35_RESULTS.json](T35_RESULTS.json)，包含完整协议、折计划、代码与特征哈希。可用 `python -m src.rolling_validation --verify-only` 从本地逐样本预测重算并核对。

## 协议（拟合前冻结）

- **输入**：已验签的 T19 冻结队列（shared1d 候选、full7d 跨度、0.5 覆盖率标签）和 T20 的 1/3/7 天 bounded 特征，全部只读。
- **模型**：沿用 T21/T22 的 historical_frequency、logistic_regression 和 XGBoost（200 棵树、深度 4、学习率 0.05），seed 42，不校准，不搜索超参数。
- **折**：测试单位是单个预测时刻。验证集取测试日之前的 3 个时刻，训练集取更早的所有时刻，并要求至少 4 个训练日；相邻集合之间满足 t+24h 严格早于下一集合的第一个 t；每个集合两类样本各至少 20 个。阈值由各折验证集的最大 F1 确定。若任一模型拟合失败，该折对所有模型一起剔除；实际没有发生。
- **不确定性**：按测试日做配对块 bootstrap（1000 次，seed 42），统计量是合并 AP 之差。比较项在运行前已固定。
- **按人排序**：以（预测时刻，参与者）为单位，只看可靠标注的候选，且该单位至少有一个正例；按概率降序、伙伴 ID 升序排名；Precision@K 定义为命中数/K。

## 解读与限制

- 在 11 个滚动测试日上，"历史越长越好"和"XGBoost 优于简单基线"这两个方向都稳定成立，与 T22 的 4 天结果一致。7d−1d 的 AP 差为 +0.090，T22 为 +0.103。
- **测试日都曾经被看过。** 研究日 17–27 先后作为 T17 测试、T22 walk-forward 或 T21/T22 主测试日被评估过。T35 没有用任何测试分数做选择，但这仍然不是从未接触过的留出集。
- **区间只描述日间波动。** 区间把"天"当作独立单位，而参与者和配对会在不同天重复出现，所以它不代表对总体的推断，也不能据此声称长期泛化。
- **早期折训练很少。** 最早的折只有 4 个训练日，训练集大小随折扩张，因此各折的合并结果混合了不同训练量的模型。
- **与 T22 不可直接比较。** 样本包含 T19 中被清除或用作训练、验证的日期，总体不同于 T22 的测试集，不能和 T22 的 AP 当作同一测试集比较。
- 1d historical_frequency 的 ROC 低于 0.5、Brier 很差：在 shared1d 候选中，1 天窗口几乎所有配对的频率相同，这个结果符合预期，不代表实现有误。
- 更强的基线（Hawkes 自激过程）属于 T36，将在本冻结折计划上评估，尚未开始。
