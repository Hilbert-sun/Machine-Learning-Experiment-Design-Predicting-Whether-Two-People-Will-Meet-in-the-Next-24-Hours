# T39 · 日间表现差异分析

## 解读与限制

- **AP 低的日子主要是"正例本来就少"，不是模型变差。** 研究日 21 的 AP 只有 0.43，但当天正例率只有 5.4%，模型比随机排序好 7.9 倍，是 11 天里提升倍数最高的一天。AP 本身会随正例率上下移动，所以比较不同日子时，应该同时看 AP/正例率。
- **候选人"最近接触得有多紧密"决定了一天的难度。** 研究日 22 和 23 只有几百个候选，但这些配对平均在约 9 小时前刚接触过、过去 7 天里接触了约 3 天，所以 AP 很高（0.77、0.91）。距上次接触时间与 AP 的相关系数为 −0.86，是所有日特征里最强的。这与 T36/T37 的结论一致：信号主要来自最近接触的时间结构。
- **活跃度和扫描覆盖率与日间差异基本无关**（|ρ| ≤ 0.23）。
- XGBoost 在 8/11 天是最好的模型；Hawkes 在研究日 20–22 更好，这几天的正例率或候选规模都比较极端。
- **限制。** 只有 11 天，彼此并不独立，相关系数只是描述，不是检验。因为数据的星期起点没有确认，这里不把任何一天标成"周末"，候选数少的日子只说明当天活跃配对少。
